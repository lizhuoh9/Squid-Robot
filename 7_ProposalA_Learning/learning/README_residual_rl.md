# 별도 강화학습 보정

현재 제안서 A와 기존 딥러닝 보정을 고정한 상태에서 PPO로 두 번째 보정 정책을 학습한다.

`effort = A 기본 출력 + 기존 딥러닝 보정 + 강화학습 보정`

- 기존 딥러닝 한도: ±0.5cm/s²
- 강화학습 한도: ±0.8cm/s²
- 두 보정의 합산 제한 없음. 각 모델 한도에 따른 합계 범위는 ±1.3cm/s²다.
- 최종 구동 duty만 ±100%로 제한한다.
- 기존 음수 딥러닝 차단은 기존 모델에만 적용한다. 별도 RL 출력은 입력 범위 보호와 ±0.8 한도를 적용한다.

## 실행

프로젝트 `7_ProposalA_Learning` 폴더에서:

```powershell
python -B learning/residual_rl.py --updates 240 --envs 64
```

결과는 `artifacts/residual_rl_v1`에 저장한다. 동일 명령을 다시 실행하면 이 폴더의 결과를 덮어쓴다.

| 파일 | 용도 |
|---|---|
| actor.pt | 검증 조건과 얕은 쪽 점수로 선택한 별도 추론 정책. 128→32→16→1, 출력 tanh×0.8 |
| ppo_training_state.pt | 마지막 PPO 업데이트의 정책·가치함수·최적화 상태. RNG 상태는 미포함 |
| training_report.json | 데이터 출처, 고정 모델 해시, 학습 이력, 기존 방식과 비교 결과 |

입력은 기존 정규화 특성 125개, 실제 적용된 NN 보정값, 직전 RL 보정값, 현재 절대 수심으로 총 128개다. 미래 센서나 미래 기록 명령은 입력하지 않는다.

학습은 기존 동역학 보고서에 지정된 전체 기록 단위 분리를 유지한다. train만 PPO 환경 초기화에 사용한다. 75%는 오차 4cm·속도 6cm/s 이내, 25%는 전체 train에서 뽑는다. validation에서 얕은 쪽 개선과 다른 지표 비악화 조건을 통과한 정책을 우선 선택하고, 그 안에서 얕은 쪽 평균·최대 이탈 점수로 고른다. 아무 정책도 통과하지 못하면 실패한 연구용 후보를 저장하되 eligible=false로 표시한다. 선택 후 test를 평가한다. 최근 수중 로그를 추가로 읽거나 동역학 모델을 재학습하지 않는다.

보상은 수심 오차, 얕은 쪽 추가 오차(가중치 12), 1.5초 정속 예상의 얕은 쪽 이탈(가중치 4), 얕은 쪽 최대 이탈 제곱 증가(가중치 3), 속도, RL 출력, 방향 전환과 출력 변화에 벌점을 준다. 학습 보상은 1/50로 스케일하며 보고서의 물리 비용은 원래 단위다. 물리 모델은 50ms, 제어는 100ms, 에피소드는 4초다. 기존 펄스와 제어 이득, bias 감소를 시뮬레이션에 포함한다.

## 결과 해석

`acceptance_passed`가 true여도 실제 수중 성능을 보장하지 않는다. 평균 오차뿐 아니라 얕은 쪽 이탈, 깊은 쪽 최대 이탈, 전환 횟수, 목표 근처 오차도 확인해야 한다. 정책이 실패한 경우 자동으로 0 정책으로 바꿔 성공처럼 표시하지 않는다.

이 단계는 PC 학습과 평가까지만 수행한다. ESP-DL 변환·펌웨어 연결·빌드·업로드는 하지 않는다. 기존 `hybrid_mpc_v1` 모델 파일도 바꾸지 않는다.

기존 학습 동역학의 오차, 센서 지연의 근사, 200ms 방향 전환 잠금 가정, 4초보다 긴 진동을 충분히 보지 못하는 한계가 있다. 기존 평가 데이터는 이전 개발에서도 사용돼 완전히 새로운 독립 검증으로 볼 수 없다. 현재 시뮬레이션 지표를 실제 수중 CSV 오차와 직접 비교하면 안 된다.
