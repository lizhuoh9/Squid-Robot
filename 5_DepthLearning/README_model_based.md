# 수심 제어: 예측 모델 기반 보정 학습 v1

## 현재 구성

실제 CSV의 제어 출력과 이후 수심 변화를 이용해 신경망 동역학 모델 3개를
학습하고, 0.5초 단위로 3초 동안의 목표 오차·속도·모델 간 불일치를 평가합니다.
보정 후보 -20~20을 2포인트 간격으로 탐색한 뒤, 선택된 보정값을 작은
25 → 24 → 12 → 1 신경망에 학습시킵니다. ESP32-S3에서는 작은 보정 모델만
실행하며, 동역학 예측과 후보 탐색은 PC에서 수행합니다.

추가 누적 오차 항은 없습니다. 기존 PID의 I항과 제어 이득은 유지합니다.
PID 기본 출력 ±80, 모델 보정 ±20, 최종 출력 ±100 제한도 그대로입니다.
기존 PD 모델은 `artifacts/depth_model_pd_restore_1790936043/`에 보존됩니다.

## 데이터와 검증

- 학습/검증 원본: `control-1791351717.csv`, `control-1791354652.csv`
- 별도 시험 원본: `control-1791358193.csv`
- 원본 위치: `../4_PC_Console/target-pi-build/release/squid-logs/`
- 학습 408개, 검증 140개, 시험 315개의 연속 구간 표본을 사용합니다.
- 목표 변경, 잘못된 값, 0.40~0.60초 밖의 기록 간격에서 구간을 끊습니다.
- 기본 출력 ±80을 넘는 수동 제어와 전진 중인 기록은 제외합니다.
- 학습/검증은 구간 단위로 분리합니다. 정규화와 bootstrap은 학습에만 적용합니다.
- 시험 파일의 이후 수심은 모델 학습, 정답 보정 생성 또는 checkpoint 선택에 사용하지 않습니다.
- 원본 CSV는 수정하지 않으며 보고서에 SHA256을 기록합니다.

시험 데이터의 다음 수심 변화 예측 MAE는 약 0.351cm입니다. 일정 속도
기준 예측의 MAE는 약 0.555cm입니다. 이는 **0.5초 뒤 변화 예측 오차**이며
목표 수심 유지 오차가 아닙니다. 양자화된 작은 제어 모델과 탐색 교사의
보정값 차이는 평균 약 5.70 출력 포인트입니다.

## 입력과 안전 제한

각 프레임의 입력은 목표-현재 수심, 속도, 가속도, 현재 PID 기본 출력,
현재 기본 출력에서 계산한 PWM입니다. 오래된 프레임부터 5개를 연결합니다.
CSV의 PWM은 출력 후 값이고 기존 추론 인자는 출력 전 값이라 시점이 다릅니다.
마지막 입력을 현재 기본 출력으로부터 동일한 반올림 규칙으로 계산하여
학습과 실제 입력을 일치시킵니다. 원본 CSV 기록 항목은 변경하지 않습니다.

오차가 15cm를 넘거나 속도가 5cm/s를 넘으면 보정은 0이며 기본 PID만
사용합니다. 정규화된 입력이 학습 평균에서 6 표준편차를 벗어나도 보정은
0입니다. 해당 조건, 센서 이상, 기록 공백 또는 목표 변경 후에는 5개 프레임을
다시 모읍니다. 첫 보정까지 약 2초가 필요하며 이후 0.5초마다 추론합니다.
조건이 바뀌면 기본 PID 사용으로 복귀합니다. 기존 ±0.2cm 데드존과 출력
8포인트 미만의 펌프 정지 규칙은 변경하지 않았습니다.

## 한계

이 빌드는 실험용이며 수심 유지 개선을 아직 실측하지 않았습니다.

0.5초마다 저장된 출력이 다음 기록까지 적용된다고 근사하지만 실제 PID는
그보다 빠르게 갱신됩니다. 목표 근처에서 출력이 크게 바뀌면 모델 오차가
커질 수 있습니다. 현재 자료는 전진하지 않은 상태이므로 전진 중 성능은
검증되지 않았습니다. 기록된 상태에서 여러 보정값을 비교하는 계산은
관측되지 않은 제어 결과를 추정하므로 정확한 인과관계를 보장하지 않습니다.

교사는 미래 3초 동안 PID 기본 출력과 보정값이 유지된다는 가정으로 후보를
비교합니다. 완전한 PID 폐루프 시뮬레이션이나 온라인 MPC가 아닙니다.
모델 간 불일치 페널티와 학습 상태 근접 검사는 위험을 줄이는 휴리스틱이며
안전 인증이 아닙니다. 학습 교사의 예측 비용 감소는 실제 수심 오차 감소와
다릅니다. 보정 모델에도 평균 약 5.7포인트의 모방 오차가 있습니다.

## 다시 학습하기

`5_DepthLearning`에서 PyTorch·NumPy가 설치된 Python으로 실행합니다.
기존 결과를 덮어쓰지 않도록 비어 있는 새 출력 폴더를 지정하십시오.

```powershell
python -B -m learning.model_based.train `
  --train-csv ../4_PC_Console/target-pi-build/release/squid-logs/control-1791351717.csv ../4_PC_Console/target-pi-build/release/squid-logs/control-1791354652.csv `
  --test-csv ../4_PC_Console/target-pi-build/release/squid-logs/control-1791358193.csv `
  --output-dir artifacts/depth_model_based_v1 --epochs 400 --seed 42

python -B -m learning.model_based.export --model-dir artifacts/depth_model_based_v1
python -B -m learning.model_based.verify --model-dir artifacts/depth_model_based_v1
```

변환에는 ONNX·ESP-PPQ도 필요합니다. 양자화는 학습 구간만 사용하며 출력
-20/+20 표현 범위, 직렬화된 scale, float/INT8 차이를 검사합니다.
`DepthResidualModelConfig.h`와 `.espdl` 파일은 반드시 함께 사용하십시오.
전용 exporter는 탐색 교사의 정답을 사용합니다. 기존 `learning.export_espdl`의
PD 교사 라벨 재생 방식으로 이 모델을 변환하지 마십시오.

제어기의 `main/CMakeLists.txt`가 새 모델 폴더를 지정합니다. 새 헤더의
`SQUID_DEPTH_MODEL_BASED` 표시가 입력 변환과 안전 제한을 활성화합니다.
예전 모델 폴더로 돌아가면 해당 표시가 없는 헤더를 통해 기존 입력 방식을
사용합니다. 학습·빌드는 로봇에 자동으로 업로드하지 않습니다.

방법의 참고 배경은 신경망 동역학 앙상블과 예측 제어를 결합하는
[PETS 연구](https://proceedings.neurips.cc/paper/2018/hash/3de568f8597b94bda53149c7d7f5958c-Abstract.html)입니다.
이 구현은 해당 논문의 알고리즘 전체를 재현한 것이 아니라, 이 로봇의 작은
오프라인 데이터와 ESP32-S3 제약에 맞춘 제한된 후보 탐색·모방 학습입니다.
